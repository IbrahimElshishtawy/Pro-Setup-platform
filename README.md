# Kitchen Pro — Modern Stainless Steel Architectural Website

موقع تعريفي ومعماري لشركة **Kitchen Pro** المتخصصة في تصميم وتصنيع المطابخ الاستيل العصرية، الشبابيك المعمارية، ووحدات الدريسنج روم.

## Design Direction
- **Style:** Modern Minimal Industrial / Modern Stainless Steel
- **Typography:** `IBM Plex Sans Arabic` + `IBM Plex Mono`
- **Design Tokens:** Centralized in `src/styles/index.css` (`#8C9298`, `#25292D`, `#343A40`, `#F5F5F2`, `#E5E7E8`, `#526D82`)

## Commands

```bash
# Development server
npm run dev

# Type check + Production build
npm run build

# Local Firebase Hosting emulator
npm run firebase:emulate

# Deploy temporary preview channel
npm run firebase:preview

# Deploy to Firebase Hosting (production)
npm run deploy
```

See [DEPLOYMENT.md](./DEPLOYMENT.md) for complete Firebase Hosting setup and deployment instructions.
